УСТАНОВКА
1. Обновите игру и полностью закройте Arknights и лаунчер Yostar.
2. Распакуйте ВЕСЬ архив в любую папку.
3. Дважды кликните на Arknights_PC_RU_Installer.exe.
4. Если игра не найдётся автоматически, выберите папку Arknights_EN.
   Она находится примерно по такому пути:
   "Ваш_диск":\"выбранная_папка_установки"\YostarGames\Arknights_EN
5. Выберите установку или обновление русификатора. Установщик проверит
   совместимость клиента и целостность игровых файлов перед изменениями.
6. После сообщения об успешной установке запустите игру обычным способом.


УДАЛЕНИЕ
Полностью закройте игру и лаунчер. Запустите Arknights_PC_RU_Installer.exe
и выберите удаление русификатора.

Если чистых резервных копий нет или игра успела обновиться, следуйте указаниям
установщика. Для полного восстановления может потребоваться Full Repair
в лаунчере Yostar.
